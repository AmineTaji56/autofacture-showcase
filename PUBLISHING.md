# Publish to GitHub

Suggested repository name: **autofacture-showcase**

Suggested description: **A visual case study of AutoFacture, a Laravel + React invoice workspace with human review and vendor extraction templates.**

Suggested topics: `portfolio`, `case-study`, `invoice-management`, `laravel`, `react`, `inertiajs`, `fastapi`, `ui-design`.

1. Create an empty repository on GitHub, without adding a README, license, or gitignore.
2. Open a terminal in this folder.
3. Run `git init -b main` if this folder has not already been initialized.
4. Run `git add README.md PUBLISHING.md .gitignore docs screenshots`.
5. Run `git commit -m "Add AutoFacture portfolio showcase"`.
6. Add the remote using `git remote add origin` followed by the GitHub repository URL.
7. Run `git push -u origin main`.

The README and gallery render directly on GitHub. No build, hosting, application source, or GitHub Pages configuration is required.
